# Документація користувача / адміністратора

## Вхід до адміністративної панелі

Адміністративна частина доступна за адресою:

```text
/admin
```

Для входу використовується email та пароль адміністратора, створені під час розгортання або через Laravel Tinker.

## Основні розділи адмінпанелі

Після авторизації адміністратор може керувати такими динамічними розділами сайту:

- **Слайдер** — керування слайдами головного банера;
- **Напрями діяльності** — додавання, редагування, деактивація напрямів;
- **Наші можливості** — керування можливостями Наукового парку;
- **Категорії новин** — створення та редагування категорій;
- **Новини** — створення, редагування, публікація, архівація та видалення новин.

## Керування новинами

1. Перейти до розділу **Новини**.
2. Натиснути **Додати**.
3. Заповнити українську та англійську версії заголовка, опису й тексту.
4. Обрати категорію.
5. Додати головне зображення та, за потреби, галерею.
6. Вказати дату публікації.
7. Зберегти запис.

Новини з майбутньою датою публікації не відображаються на сайті до настання цієї дати. Архівні новини також приховані від публічного перегляду.

## Керування слайдером

У розділі **Слайдер** адміністратор може:

- додавати слайди;
- редагувати заголовки українською та англійською;
- змінювати опис;
- завантажувати зображення;
- задавати порядок відображення;
- активувати або приховувати слайди.

Максимальна кількість активних слайдів обмежена системою.

## Мовні версії

Сайт підтримує дві мови:

- українська — основна;
- англійська.

Перемикання мови доступне в шапці сайту через перемикач `UA | EN`.

## Пошук новин

На сторінці новин доступний пошук за:

- заголовком;
- коротким описом;
- текстом новини;
- категорією;
- роком публікації.
