# Інструкція для викладача

## 1. Посилання на проєкт

### GitHub-репозиторій

```text
https://github.com/VasylyshynDavid/polissia-science-park
```

### Демо-версія сайту

```text
https://polissia-science-park.onrender.com
```

> Примітка: безкоштовний тариф Render може переводити сайт у режим сну. Перше відкриття після паузи може тривати 30–60 секунд.

## 2. Адміністративна панель

Адреса адміністративної частини:

```text
https://polissia-science-park.onrender.com/admin
```

Дані для входу:

```text
Email: test@example.com
Password: password
```

---

## 3. Що можна перевірити в адміністративній панелі

Після входу доступні розділи керування контентом:

- **Слайдер** — керування головним банером;
- **Новини** — додавання, редагування, публікація та архівація новин;
- **Категорії новин** — керування категоріями;
- **Напрями діяльності** — керування блоком напрямів діяльності;
- **Наші можливості** — керування блоком можливостей.

---

## 4. Публічна частина сайту

На сайті реалізовано:

- головну сторінку згідно з дизайнерською концепцією;
- дві мовні версії: українську та англійську;
- перемикач мов `UA | EN`;
- розділ новин;
- сторінки напрямів діяльності;
- сторінку можливостей;
- контакти у футері;
- пошук новин;
- SEO-метадані, Open Graph, Schema.org, robots.txt та sitemap.xml.

## 5. Технічна інформація

Проєкт реалізовано на:

- PHP 8.2+;
- Laravel 12+;
- MySQL/MariaDB або SQLite для демонстраційного середовища Render;
- HTML5;
- CSS3;
- JavaScript.

## 7. Резервне копіювання

У проєкті передбачена команда для створення резервної копії бази даних:

```bash
php artisan db:backup
```

Резервні копії створюються в директорії:

```text
storage/app/backups
```

---

## 8. Примітка щодо демо-хостингу

Демо-версія розгорнута на Render Free. Через особливості безкоштовного тарифу можливі:

- повільний перший запуск після простою;
- перезапуск середовища після redeploy;
- тимчасова недоступність під час автоматичного оновлення.

Для постійного production-розгортання рекомендовано використовувати університетський сервер, VPS або Laravel-хостинг із MySQL/MariaDB та HTTPS.
